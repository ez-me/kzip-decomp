# kzip-decomp
This is a clean-room reverse engineering of [Ken Silverman's](https://advsys.net/ken/) [kzip](https://advsys.net/ken/utils.htm).
Specifically the [linux port](https://advsys.net/ken/utils.htm) by [Jonathon Fowler](https://www.jonof.id.au/) 

Currently it's a functional decomp which isn't binary identical, but it has the same behaviour everywhere else.
